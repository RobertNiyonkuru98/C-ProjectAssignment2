# P2 - Dynamic Text Mining and Linguistic Pattern Analyzer

## What the program does

The program reads a paragraph, breaks it into words, counts how often each word
is used, and runs several analysis operations on it:

```
------------------------- MENU -------------------------
 1. Count the words in the text
 2. Find the longest word
 3. Find the most frequent word
 4. Show every word and its frequency
 5. Sort the word list (alphabetical / frequency)
 6. Search for a word
 7. Show the text summary
 8. Custom analysis - Lexical Diversity Score
 9. Show the memory addresses
10. Enter or paste a new paragraph
11. Exit
--------------------------------------------------------
```

The starting paragraph is the Gettysburg Address (Abraham Lincoln, 1863),
271 words. Option 10 lets the user paste a different paragraph of any length.

### 1. The two structures

```c
typedef struct {
  char name[WORD_MAX];   // 40 characters, so 39 letters plus the terminator
  int count;
} wordStat;

typedef struct {
  char *text;            // the paragraph, on the heap
  int text_len;
  int text_cap;

  wordStat *stats;       // one entry per distinct word, on the heap
  int distinct;
  int stats_cap;

  int total_words;
  int truncated_words;
} Text;
```

### 2. How the text is stored without a fixed length

The buffer starts at 512 bytes with `calloc`. Every time a line is added,
`append_text()` checks whether it still fits. If it does not, the buffer is
doubled with `realloc` and the old contents are kept. Nothing in the program
assumes a maximum paragraph length.

The word list works the same way: it starts with 16 slots and doubles each time
a new distinct word arrives.

Both `realloc` calls use a temporary pointer, so a failed allocation leaves the
old block in place and the text is not lost.

### 3. How words are extracted

Word extraction walks the text with a pointer instead of an index:

```c
while (*p != '\0') {
  while (*p != '\0' && !isalpha((unsigned char)*p)) p++;   // skip separators
  ...
}
```

The rules, which the brief asks to be documented:

| Character | Treatment |
|---|---|
| letters | make up a word |
| apostrophe `'` and hyphen `-` | stay inside a word when they sit between two letters, so `don't` is one word and `battle-field` is one word |
| digits | separate words |
| spaces, commas, full stops, new lines, quotes | separate words |
| upper and lower case | folded to lower case, so `The` and `the` count as the same word |
| a word longer than 39 characters | cut to 39 characters, and the cut is counted and reported |

Duplicate words are found by comparing each new word against the existing list
with `strcmp()`. `strlen()` is used for lengths and `strcpy()` copies the word
into the statistics array once it is known to fit.

### 4. Memory addresses

The brief asks for the addresses of the two heap structures to be printed:

```
  Text buffer address     : 0x557b81fcfb90
  Word statistics array   : 0x557b81fd03a0
  First word-stat entry   : 0x557b81fd03a0
  Second word-stat entry  : 0x557b81fd03cc
```

The first two entries are 44 bytes apart, which is exactly `sizeof(wordStat)`:
40 for the name and 4 for the count. The addresses differ on every run because
the program asks the operating system for memory each time it starts.

### 5. Custom analysis - Lexical Diversity Score

The score compares how many different words were used with how many words there
are in total:

```
Lexical Diversity Score = 100 * distinct words / total words
```

A score near 100 means almost every word is a new one. A low score means the
same words keep coming back. On the Gettysburg Address:

| Measure | Value |
|---|---|
| Total words | 271 |
| Distinct words | 138 |
| Score | 50.9 percent - moderate diversity |
| Words used more than once | 47 of 138 |

The program also prints a warning that short texts always score higher, because
there is less opportunity to repeat a word. That is why the second test
paragraph (23 words) scored 65.2 percent even though it repeats its own words.

### 6. What the run showed

`outputs/sample_run.txt` contains the whole session. Some results:

- 271 words found in the starting paragraph
- longest word `battle-field`, 12 characters - the hyphen was kept inside the word
- most frequent word `that`, 13 times
- searching for `the` returned its frequency
- the word list sorted by frequency and then displayed
- a new paragraph of 23 words accepted, and the statistics rebuilt from it
